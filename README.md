## 📋 Descrição

Gerador de pastas e arquivos que seguem um modelo, para ajudar na automação. 

O gerador funciona através das configuracoes que voce passa na classe CONFIGURATION, lá você pode definir nomeclaturas de Pastas, Arquivos e Classes.
